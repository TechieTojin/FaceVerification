# Screenshots

Screenshots must be captured manually from the running application.
No automated screenshot capture is available in this environment.

## How to capture

1. Start both servers (see root README).
2. Open http://localhost:5173 in your browser.
3. Log in with your admin credentials.
4. Navigate to each page and take a screenshot.

## Required screenshots

| File | Page | Notes |
|---|---|---|
| `login.png` | Login page | Remove credentials before capturing |
| `dashboard.png` | Dashboard | Use realistic but non-personal data |
| `verification.png` | Live Verification | Start a session; capture the webcam view with state overlay |
| `users.png` | User Management | Use test accounts only |
| `enrolment.png` | Enrolment | Capture the consent/capture steps |
| `analytics.png` | Analytics | After some verification activity |
| `security.png` | Security Center | After some events have been logged |
| `settings.png` | Settings | Admin policy controls |

## Privacy rules

- Do not include real biometric images or facial photographs.
- Do not include real personal names, email addresses, or user IDs.
- Do not include authentication tokens, JWT values, or credentials.
- Do not include sensitive form values.
- Blur or crop any personally identifying information before committing.

Once captured, place files here and update README.md image references.
